# Touchline FC 3D 1.9.0

Python + Panda3D로 만든 3D 축구 게임입니다. 구단 관리, 시즌 카드, 11대11 경기와 직접 접속 온라인 친선전을 제공합니다.

## Windows에서 실행

1. TouchlineFC3D_Windows.zip을 **새 폴더에 모두 압축 풀기** 합니다.
2. **START_GAME.bat**를 더블클릭합니다.
3. 창이 열리지 않으면 **START_COMPATIBLE.bat**를 실행합니다. CPU로 3D를 그리는 호환 모드입니다.
4. 오류 기록은 **SHOW_ERROR.bat**로 엽니다.

Python이나 언리얼 엔진을 별도 설치할 필요가 없습니다. Windows 10/11 x64용입니다.
EXE, DLL, assets 폴더를 모두 함께 두어야 합니다. 구버전 파일과 섞지 마세요.
Windows 실행본은 Linux에서 교차 빌드했습니다. 실제 Windows PC에서의 실행 검증은 하지 못했습니다.

## 1.9.0 골·판정 시네마틱과 CPU 판단

- 골 세레머니에서는 얼굴·머리카락·유니폼과 손을 더 세밀하게 만든 3D 모델을 사용합니다. 낮은 전신 시점에서 근접 시점으로 넘어가며, 리플레이는 실제 슈팅의 공과 선수 움직임을 재생하고 골문 앞에서 카메라를 바꿉니다.
- 오프사이드와 파울, 코너킥, 골킥, 스로인, 페널티킥은 심판이 휘슬을 불고 방향이나 카드를 보여 주는 장면부터 시작합니다. 연출과 선수 정렬이 끝나면 기존 방식으로 킥을 조작합니다.
- CPU는 공이 노출된 쪽에서 태클하고 상대 뒤에서 무리하게 발을 뻗지 않습니다. 직접 프리킥은 골문까지의 거리와 각도, 골키퍼·수비벽 위치를 보고 슛을 고릅니다. 먼 곳이나 각도가 좁은 곳에서는 패스 길과 동료 위치를 보고 이어갑니다.

**훈련·세트피스 → 골·세레머니·리플레이**, **오프사이드 훈련** 또는 다른 세트피스에서 볼 수 있습니다. 지원되는 GPU에서는 시네마틱 배경에 초점 흐림과 색 보정을 적용합니다. 호환 모드에서도 카메라·모델·판정 모션이 표시됩니다.

## 1.8.0 경기 규칙

**3D 경기 시작** 또는 온라인 **방 열기**에서 경기 방식을 선택합니다. **일반 경기**는 정규 시간 동점을 무승부로 처리합니다. **승부 결정전**은 정규 시간 동점이면 연장 전·후반을 진행하고, 그래도 동점이면 승부차기로 넘어갑니다.

- **오프사이드**는 동료가 공을 찬 시점의 선수 위치를 기준으로 삼습니다. 상대 진영에서 공과 뒤에서 두 번째 상대보다 앞선 선수가 공을 터치하거나 가까운 경합에 개입하면 상대의 간접 프리킥으로 재개합니다. 코너킥·골킥·스로인을 직접 받을 때는 예외입니다. 위치는 3D 선수 모델의 중심 좌표로 계산합니다.
- **파울과 카드**는 태클 종류, 접근 방향·속도 및 득점 기회를 바탕으로 판정합니다. 경고 두 장 또는 레드카드로 퇴장하면 해당 선수는 경기에서 빠집니다. 골키퍼가 퇴장하면 남은 필드 선수 한 명이 골키퍼를 맡습니다. 팀원이 7명 미만이면 경기를 중단하고 게임 기록에는 상대 팀 승리를 반영합니다.
- **승부차기**에서는 양 팀이 같은 수의 출전 가능 선수로 번갈아 찹니다. 기본 5회씩 진행하고, 따라잡을 수 없는 점수 차에서는 조기에 끝납니다. 5회씩 찬 뒤에도 동점이면 양 팀이 한 번씩 더 차는 방식으로 승부를 냅니다. 결과와 보상에는 승부차기 승패를 반영하며, 경기 득점은 별도로 집계합니다.
- **공이 전부 라인을 넘어야** 득점이나 아웃입니다. 간접 프리킥은 다른 선수가 터치해야 득점할 수 있고, 재개한 선수가 다른 선수의 터치 전에 공을 다시 건드리면 상대 간접 프리킥입니다.

**훈련·세트피스 → 오프사이드 훈련 또는 승부차기 훈련**에서 바로 확인할 수 있습니다. 승부차기에서 공격은 방향키로 조준하고 **D를 눌러 충전한 뒤 놓습니다**. 골키퍼는 좌우로 움직이고 **좌우 방향키 + D**로 다이빙합니다.

## 1.7.1 헛다리 짚기

공을 소유한 상태에서 **Shift + ↑** 또는 **Shift + I**를 누르면 오른발로 헛다리를 짚습니다. **Shift + U**는 왼발, **Shift + O**는 오른발입니다. 공을 발 가까이 둔 채 축구화가 공 앞을 돌아 나옵니다. 발을 바깥으로 내딛을 때 원하는 방향키를 누르고 있으면 그쪽으로 드리블을 이어갑니다. 홈의 **훈련·세트피스 → 개인기 훈련**에서 연습할 수 있습니다.

## 1.7.0 달리기와 방향 전환

패스·슛의 4칸 게이지가 0.78초에 가득 찹니다. 키를 떼는 순간 공을 찹니다. 공 지름을 23cm에서 32.2cm로 키우고 흰색·검은색 패널을 적용했습니다.

E를 누른 채 방향키나 IJKL을 바꾸면 완만한 턴에서는 속도를 유지하기 쉽습니다. 90도로 꺾으면 바깥발을 디디고 무릎을 굽혀 감속한 뒤 새 방향으로 가속합니다. 180도로 돌면 한 번 거의 멈춥니다. 사용자·상대·동료 AI는 같은 이동 계산을 사용합니다. 중계 시점과 근접 시점 모두 고관절·무릎·발목이 움직입니다.

## 1.6.0 패스와 슛 조작

공을 가진 상태에서 **S(패스), W(스루패스), A(로빙·크로스), D(슛)**를 누르면 왼쪽 아래 선수 이름 위의 4칸 게이지가 찹니다. **눌렀던 키를 떼면** 그때의 세기로 한 번 찹니다. 가볍게 눌렀다 떼면 짧고 약하게, 길게 눌렀다 떼면 더 강하게 찹니다. 끝까지 채운 상태에서도 키를 놓을 때까지 기다립니다. Z+S, Q+W, Z+D, Q+D에도 같은 조작을 사용합니다. 휘슬과 선수 정렬이 끝나면 세트피스에서도 게이지를 쓸 수 있습니다.

패스할 때 방향키로 동료가 있는 쪽을 향하세요. 같은 방향에 동료가 여럿이면 게이지를 짧게 채울수록 가까운 동료, 길게 채울수록 먼 동료를 우선합니다. 받는 선수는 패스 궤도로 이동해 발에 닿는 공을 자동으로 잡습니다. E와 방향키를 계속 누르고 있어도 되고, 공을 잡는 순간 그 방향으로 첫 터치합니다. 받을 때는 S를 다시 누를 필요가 없습니다. 공이 떠 있을 때 가까운 공중볼 헤딩과 수비 조작은 키를 누르는 즉시 시도합니다.

구르는 공은 잔디 저항으로 점차 느려지다가 멈춥니다. Z+S로 더 빠른 땅볼 패스를 보낼 수 있습니다. 수비수가 패스 경로에 먼저 들어와 닿으면 가로챌 수 있습니다.

## 1.5.0 카드·선수 외형·개인기·세레머니·골 리플레이

- 실제 선수 **160명**, **594종 카드**, **7개 시즌**입니다. 24/25·25/26·26 LIVE·23/24·22 WC·24 EURO·18 WC를 제공합니다. 새 선수 전체에 현재 LIVE 카드를 일괄 부여하지 않습니다. 대회 카드는 실제 경기 출전 기록을 확인해 생성합니다.
- 방패형 카드, 시즌별 프레임·색상, OVR·포지션·국적·선수명 표시를 새로 만들었습니다. 이적시장에 한글/영문 선수 검색을 추가했습니다.
- 사용 조건을 확인한 실제 선수 사진 134명분을 적용했습니다. 나머지 26명은 선수별 자체 3D 초상입니다. 사진 출처·저작자·개별 라이선스는 **PHOTO_CREDITS.md**와 assets/photos/attribution.json에 있습니다. 사진은 시즌 당시의 사진을 모두 따로 재현한 것이 아닙니다.
- 팩은 전용 경기장 터널에서 국적 → 포지션 → 시즌 → OVR → 카드 순서로 공개합니다. 등급별 색상, 조명·입자, 카드 등장과 효과음이 있고 건너뛰기도 됩니다. 카드는 구매 1회에 한 번만 지급되며 연출을 닫아도 보유됩니다.
- 네모 몸체를 둥근 인체 비율, 무릎·팔꿈치 관절, 선수별 키·체형·헤어스타일로 교체했습니다. 얼굴 영역을 확인한 사진 126명분은 간이 얼굴 표면에 텍스처로도 표시합니다. 정밀 스캔 모델, 전문 모션 캡처, 원작과 동일한 페이스온은 아닙니다.
- 기본 성능 우선 모드는 멀리 있는 선수의 메시를 간소화합니다. 조작 선수와 가까이 보이는 선수·세레머니는 상세 모델을 사용합니다. 모델을 재사용하고 기록 버퍼 크기도 제한했습니다.
- **개인기 4종**: 스텝오버, 룰렛, 볼 롤, 힐 플릭. 실제 공 위치·움직임과 모션이 바뀝니다. 재사용 대기와 체력 소모가 있으며 무적 효과는 없습니다.
- **세레머니 4종**: 양팔 들기, 무릎 슬라이딩, 점프 턴, 하트. 득점 뒤 1~4로 선택합니다.
- 득점 뒤 세레머니 → 실제 골 장면 0.65배속 재생 → 상대 킥오프로 이어집니다. 득점 직전 최대 약 6초의 선수·공 움직임을 기록해 재생합니다. 골 장면을 따로 꾸며낸 고정 영상이 아닙니다. 연출 동안 경기 시간은 멈추고 득점은 한 번만 반영됩니다.
- 프리킥·페널티킥·코너킥·스로인·골킥 앞에 휘슬 및 약 2.2초의 준비 단계를 추가했습니다. 준비 중 조기 입력으로 킥이 발동하지 않습니다. 이후에는 직접 조준하고 실행합니다.
- 효과음은 Windows 기본 오디오 기능으로 비동기 재생합니다. **M**은 효과음 켜기/끄기입니다. 헤드리스 테스트 환경에서는 실제 Windows 스피커 출력을 검증하지 못했습니다.

## 1.4.0 패스·첫 터치·시점·성능 개선

- 방향을 누르고 S를 누르면 해당 방향의 동료를 우선합니다. 그 방향에 동료가 없으면 입력 방향으로 공을 보냅니다. 방향 없이 S를 누르면 가까운 동료를 찾습니다.
- 일반 땅볼 패스의 초기 속도는 최대 26m/s, Z+S는 31m/s입니다. 거리와 감속을 함께 계산해 공이 수신 지점에 도달하게 했으며, 땅볼이 불필요하게 튀지 않습니다. 이 값은 자체 게임 밸런스값입니다.
- 패스 수신 선수는 목표 지점에서 공을 기다리고 가까워졌을 때만 마중 나갑니다. 1.6.0부터는 방향을 유지해도 공을 받기 전까지 위치 보정이 작동합니다. 공을 잡기 전에 입력한 방향으로 첫 터치합니다.
- 패스를 받는 중에도 S로 다른 선수로 바꿀 수 있습니다. 상대 수비의 패스 가로채기도 유지합니다.
- 프리킥·페널티킥은 키커와 골문이 보이는 전용 시점, 코너킥·스로인은 키커와 수신 지점이 보이는 전용 시점입니다. 킥 이후 잠시 시점을 유지한 뒤 경기 시점으로 전환합니다.
- 노란 궤적은 실제 킥과 같은 공 물리 계산을 사용합니다. 공격 키를 누르고 있는 동안 힘에 따라 바뀝니다. 선수의 접촉·태클·헤딩에 의한 이후 경로 변화는 안내선에 포함하지 않습니다.
- AI 기본 난이도는 **쉬움**입니다. 설정에서 쉬움/보통/어려움을 바꿉니다. 난이도는 반응 시간, 압박 인원, 질주 선택과 슈팅 판단·오차를 바꿉니다. 양 팀의 능력치 85와 최고 속도 계산은 같습니다.
- 기본은 **1280×720 / 성능 우선**입니다. 선수의 움직이는 관절은 유지하면서 메시를 묶고, 경기장 고정 구조와 HUD 갱신을 최적화했습니다. 메뉴는 30FPS, 경기는 60FPS 상한으로 동작합니다. 실제 FPS 보장은 아닙니다.
- 성능 우선에서는 개별 관중을 숨깁니다. 설정에서 관중 표시로 되돌릴 수 있습니다. 경기 시간·난이도·그래픽 품질이 자동 저장됩니다.
- 느리면 **START_LOW.bat**로 GPU 렌더링을 유지한 1024×576 창을 사용할 수 있습니다. START_COMPATIBLE.bat는 그래픽 드라이버 문제를 위한 CPU 호환 모드라서 더 느릴 수 있습니다.

측정 결과와 실제로 점검한 범위, 남아 있는 제한은 **REVISION_REPORT_KO.md**에 기록했습니다.

## 1.3.0 조작·수비·패스 개선

- 방향키와 IJKL을 함께 지원하며 E를 누른 채 계속 방향을 바꿀 수 있습니다. 대각선 이동 속도는 직선과 같습니다.
- Space를 스탠딩 태클에 배정했습니다. A는 슬라이딩 태클입니다.
- Z+D는 감아차기입니다. D를 누를 때의 조합을 기억하므로 Z를 먼저 놓아도 감아차기로 실행됩니다.
- 패스 대상 선수가 공의 예상 경로로 자동 이동하고, 공이 몸 가까이 오면 자동 트래핑합니다. 방향 입력으로 계속 조작할 수 있습니다.
- 흰색 빈 삼각형은 수비 시 다음 S 전환 대상입니다. 실제 선수 전환과 같은 판정을 사용합니다.
- AI가 드리블하는 상대를 달려서 압박하고, 두 번째 수비수는 커버하며 나머지는 공격수를 마크하고 골문 쪽으로 복귀합니다.
- 경기 능력치를 모든 선수에게 85로 통일했습니다. 사용자, 동료 AI, 상대 AI 모두 같은 속도·달리기·체력·태클·공 수신 계산을 사용합니다.
- 공정 경기의 85는 경기 중 적용값입니다. 구단·이적시장 카드의 원래 능력치는 유지합니다. 공 소유 여부와 현재 체력에 따른 변화도 양 팀에 똑같이 적용됩니다.

## 1.2.0에서 추가한 기능

- 코너킥·프리킥·페널티킥·스로인·골킥: 준비 → 조준 → 힘 조절 → 실행 모션 → 경기 재개.
- 사람이 차는 세트피스는 입력 없이 자동으로 드리블하거나 진행하지 않습니다.
- 스로인은 양손을 머리 위로 올려 던집니다. 스로인으로 직접 골이 들어가면 인정하지 않습니다.
- 프리킥 수비벽과 페널티 지역 안 반칙에 따른 페널티킥, 페널티킥 골키퍼 조작.
- 헤딩: 공중볼에 맞춰 점프하고 머리로 공의 방향·속도를 바꿉니다.
- 스탠딩 태클, 슬라이딩 태클, 하드 태클, 넘어짐·회복 모션을 구분했습니다.
- 초기 1.2.0에는 현역 선수 27명·3개 시즌·81종을 수록했습니다. 현재는 160명·7개 시즌·594종입니다.
- 같은 선수의 다른 시즌은 수집할 수 있지만 동시에 선발할 수 없습니다.
- 조작을 FC 온라인 기본 키보드 배치에 맞췄습니다.
- 경기 종료 후 홈 복귀 시 화면을 잘못 정리하던 오류를 수정했습니다.

## 기본 키

| 상황 / 동작 | 키 |
| --- | --- |
| 이동 | 방향키 ↑ ↓ ← → 또는 I(위) J(왼쪽) K(아래) L(오른쪽) |
| 달리기 | E 유지 + 방향키 또는 IJKL |
| 짧은 패스 / 가까운 공중볼 헤딩 패스 | S |
| 수비 선수 변경 | S |
| 슛 / 공중볼 헤딩 | D |
| 스탠딩 태클 | Space (수비 D도 유지) |
| 크로스·로빙패스 / 수비 슬라이딩 태클 | A |
| 스루패스 | W |
| 로빙 스루패스 | Q + W |
| 칩슛 | Q를 누른 채 D |
| 감아차기 | Z를 누른 채 D |
| 강한 땅볼 패스 | Z + S |
| 공 지키기·느린 이동 | C 유지 |
| 공격 침투 요청 / 수비 도움 요청 | Q |
| 수비 하드 태클 | F |
| 골키퍼 전진 | 수비 시 W 유지 |
| 슬라이딩 후 빠르게 회복 | 슬라이딩 중 A 한 번 더 |
| 일시정지·경기 메뉴 | Esc |
| 전체화면 | Alt + Enter |
| 카메라 | 경기 화면 우측 위 '시점' 버튼 |

S·W·A·D는 공격 시 누른 시간으로 힘을 조절하고 뗄 때 실행합니다. 감아차기는 Z를 누른 채 D를 누르면 됩니다.
공중볼 헤딩과 수비 태클은 버튼을 누를 때 시도합니다.
민트색 원은 조작 중인 선수, 금색 원은 공을 소유한 선수입니다.
이 게임에 구현한 동작에 FC 온라인 기본 키를 적용했습니다. 모든 고급 개인기와 수비 방식이 구현된 것은 아닙니다.

## 특수 상황을 직접 조작하기

홈의 **훈련·세트피스**에서 코너킥, 프리킥, 페널티킥, 스로인, 헤딩을 각각 연습할 수 있습니다.
훈련은 경기 보상을 지급하지 않습니다.

| 상황 | 조작 |
| --- | --- |
| 코너킥 | 좌우로 목표 이동, 위아래로 거리 조절 → A를 누른 뒤 떼어 크로스, S는 가까운 동료에게 연결 |
| 프리킥 | 좌우로 골대 안 방향, 위아래로 높이 → D를 누른 뒤 떼어 직접 슛, A는 띄우기, S는 패스 |
| 페널티킥 | 좌우로 목표, 위아래로 높이 → D를 누른 뒤 떼기 |
| 페널티킥 골키퍼 | 좌우로 이동, 방향키 + D로 다이빙 방향 지정 |
| 스로인 | 방향키로 노란 목표 지점 조절 → S로 가까운 동료, A/D로 조준한 지점에 양손 던지기 |
| 골킥 | 방향키 조준 → A/D로 길게, S로 짧게 |
| 키커 변경 | 코너킥·프리킥·페널티킥 준비 중 E |
| 헤딩 | 공이 머리 근처로 내려올 때 D. 가까운 공중볼에 S는 동료에게, A는 멀리 걷어내기 |

CPU 상대는 준비한 뒤 직접 실행합니다. 온라인에서는 공을 가진 팀의 사용자가 직접 실행합니다.
세트피스를 준비하는 동안 경기 시간은 멈춥니다.

## 실제 선수와 출전 시즌 카드

손흥민, 리오넬 메시, 크리스티아누 호날두, 음바페, 홀란, 해리 케인, 라민 야말,
벨링엄, 페드리, 로드리, 비티냐, 브루누 페르난드스, 엔소 페르난데스, 라이스,
올리세, 크바라츠헬리아, 반데이크, 살리바, 가브리에우, 쿠바르시, 우파메카노,
하키미, 누누 멘데스, 쿠쿠렐라, 쿠르투아, 라야, 마르티네스를 수록했습니다.

시즌은 **24/25, 25/26, 26 LIVE, 23/24, 22 WC, 24 EURO, 18 WC**로 구분합니다. 시즌별 능력치는 이 게임의 자체 밸런스값입니다.
실제 선수 이름을 사용합니다. 경기 모델은 자체 제작이며 사진이 확보된 경우 카드·얼굴 표면에 개별 라이선스의 사진을 사용합니다.
이적시장의 '모든 시즌' 버튼을 누르면 시즌별 필터를 바꿀 수 있습니다.
기존 저장은 보유 카드 수·카드 ID·코인·전적을 유지하면서 현역 선수 카드로 바뀝니다.
업그레이드 전 구단은 `club.before-stars.json`으로 한 번 보관합니다.

일반 팩: BASE 78% / RARE 20% / ELITE 2%.
프리미엄 팩: BASE 20% / RARE 65% / ELITE 15%.
BASE 80–87, RARE 88–91, ELITE 92–96. 시즌은 카드 획득 결과에 표시됩니다.
이적시장은 로컬 CPU 시장이며, 판매가는 기준가의 75%입니다.

## 온라인

두 PC 모두 **1.9.0**을 사용하세요. 방을 여는 사람이 일반 경기 또는 승부 결정전을 정합니다. 접속에는 프로토콜 9를 사용합니다.

1. 호스트: 온라인 대전 → 방 열기.
2. 호스트가 자신의 IPv4 주소를 참가자에게 알려줍니다.
3. 참가자: 호스트 IP 입력 → 접속하기.
4. 호스트는 홈팀, 참가자는 원정팀을 조작합니다. 헤딩·태클 모션과 세트피스, 패스 대상, 다음 전환 커서 상태도 전송합니다.

같은 공유기/LAN에서 사용하기 쉽습니다. 같은 PC의 두 게임은 `127.0.0.1`로 연결합니다.
외부 접속에는 호스트의 TCP 7777 포트에 연결할 수 있어야 합니다. 별도의 중계·공개 매칭 서버는 없습니다.
온라인에서는 Esc 메뉴를 열어도 경기는 계속됩니다.

## 소스 실행과 검증

Python 3.10~3.13 64비트와 Panda3D 1.10.16을 사용합니다.
소스 ZIP을 압축 해제한 뒤 START_WINDOWS.bat를 실행하면 최초 한 번 의존성을 설치합니다.

```text
python -m pip install -r requirements.txt
python launch_game.py
python -m unittest discover -s tests -v
python launch_game.py --smoke
python launch_game.py --smoke --safe-mode --software
python launch_game.py --capture screenshots
python setup.py build_apps
```

구단 저장: `%LOCALAPPDATA%\TouchlineFC3D\club.json`.
설정 저장: `%LOCALAPPDATA%\TouchlineFC3D\settings.json`.
시작 오류 기록: `%LOCALAPPDATA%\TouchlineFC3D\startup.log`.
TLFC_SAVE_DIR로 구단 저장 경로를 바꿀 수 있습니다.

검증 항목은 VERIFICATION.txt에 기록합니다. 골 리플레이와 4가지 개인기를 지원합니다. 핸드볼, VAR, 경기 중 선수 교체는 재현하지 않습니다.
